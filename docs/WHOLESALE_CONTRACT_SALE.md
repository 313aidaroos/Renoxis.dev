# Wholesale contract-sale playbook (assignment / dispo)

**Purpose:** How Renoxis / Cixy helps an operator **sell the contract** (equitable interest), not the house. Paper/process for agents; wire into product later.

**Hard line:** Licensing and marketing rules vary by state. Separate (1) facts from records, (2) labeled estimates/assumptions, (3) “verify with a licensed local professional / attorney.” Never invent comps, ARVs, rents, proof of funds, or case outcomes.

---

## Opening intake (ask before advising)

1. **Market** (city / county / MSA)
2. **Role** (wholesaler / agent assisting / other)
3. **Contract status**
   - Signed purchase agreement? (yes / no / under negotiation)
   - Assignable? (yes / no / unknown — check addenda)
   - Days left to close / inspection / financing deadlines
4. **Need now:** acquisition packaging **or** dispo / buyer close
5. **Numbers on hand:** purchase price, EMD status (soft vs hard), asked assignment fee, repair/ARV *estimates* (source)

Refuse vague “get me buyers” / “assign this” without market, contract terms, numbers, and timeline.

---

## 1. Acquire equitable interest (pre-dispo)

Checklist:

- [ ] Written purchase agreement with clear parties, property, price, close date
- [ ] Assignment rights (or documented double-close plan if assignment restricted)
- [ ] Earnest money that will actually hard on the agreed clock
- [ ] Inspection / finance contingencies timed to the **exit** clock (enough runway to market + walkthrough + buyer deposit)
- [ ] Access for buyer walkthroughs (keys, lockbox, showing instructions)
- [ ] Seller disclosures collected where required; do not invent motivation stories

**Kill early if:** non-assignable with no viable double-close path; EMD that will never hard; timeline too tight to market honestly.

---

## 2. Package the deal

Deal package contents (facts vs estimates labeled):

| Section | Content | Label |
| --- | --- | --- |
| Property basics | Address, beds/baths, year, sqft (from record), occupancy | Fact from source |
| Photos | Current condition photos | Fact |
| Seller situation | Only what seller/docs state | Fact; never fabricate |
| Title / HOA / liens | Flags from prelim / seller / known issues | Fact or “verify with title” |
| Repair scope | Scope + cost *estimate* | Estimate + method |
| ARV / rent comps | Worksheet only if sourced | Source each line; else “not sourced — do not invent” |
| Numbers | Purchase, assignment fee, buyer all-in, EMD, close date | Fact / negotiated |
| Access | Walkthrough window, showing rules | Fact |
| Title / escrow | Company if known | Fact |

**Cixy rule:** Prefer inclusive, factual copy. Flag fair-housing risk language. Never invent comps.

---

## 3. Build & work a buyers list

Segments (track in CRM: leads / clients with tags):

- Cash buyers / flippers
- Landlords / buy-and-hold
- Funds / smaller operators
- By **area**, **price band**, **rehab appetite**

Hygiene:

- [ ] Consent / relationship basis for outreach (no spam, no spoofed identity)
- [ ] Last contact + interest level in Renoxis CRM
- [ ] Do-not-contact respected
- [ ] Match deal to segment before blasting

---

## 4. Dispo / pitch cadence (timed to contract clock)

Default sequence:

1. **Short teaser** — address area (not full street if needed), beds/baths, ask, assignment fee, close date, walkthrough window
2. **Full package** — to interested buyers only
3. **Live walkthrough** — scheduled; document who attended
4. **Soft commit** — verbal/email interest + remaining diligence
5. **Deposit to title / escrow** — end-buyer funds land with title, not “trust me”
6. **Assignment / closing docs** — coordinate with title/attorney

Follow-ups: T-minus inspection end, T-minus assignment deadline, T-minus close. Log every touch in CRM tasks/appointments.

**Objection handling (checklist, not scripts to deceive):** price, repairs, title flags, timeline, financing reality. Renegotiate or kill cleanly.

---

## 5. Assignment mechanics

- [ ] Assignment of contract / addendum prepared by competent local counsel or title workflow
- [ ] Disclose wholesale role **where required**
- [ ] Assignment fee structure clear in writing
- [ ] End-buyer deposit to escrow/title
- [ ] Closing coordination: dates, wire instructions from title only, who signs what

Never coach “bandaid assignment” of a non-assignable contract.

---

## 6. Double-close path

Use when assignment is banned, restricted, or buyer prefers two deeds.

- [ ] Confirm funding path (transactional funding vs true two closings)
- [ ] Same-day timing risks documented
- [ ] Disclosures as required locally
- [ ] Title company experienced with A→B→C

Verify legality and disclosure with local counsel/title — do not assume assignment rules from another state.

---

## 7. Exit hygiene

- [ ] Kill dead deals early; free the seller and your buyers list
- [ ] Renegotiate or cancel per contract; document everything
- [ ] Never ghost sellers or buyers
- [ ] Archive package + CRM notes for the file

---

## Hard refusals (wholesale)

Do **not** coach or generate:

- Fraud, straw buyers, fake proof of funds
- Undisclosed dual agency where banned
- Hiding wholesaler role when disclosure is required
- Bandaid assignment of non-assignable contracts
- Pressuring unlicensed brokerage as if legal everywhere

Always flag: **licensing and marketing rules vary by state — verify locally.**
