# Renoxis brand kit

Follows `/workspace/brand-kits/BRAND_KIT_STANDARD.md`. Load logos only from `public/brand/` (served at `/brand/…`) with these exact names. PNG/ICO only, never SVG. Never generate, redraw or recolor a logo; read colors from `brand.json`.

Source: `renoxis-logo/final/` (2026-10-17 refresh). Horizontal logo = official R mark + official RENOXIS wordmark, cropped from the stacked logo and placed side by side.

| File | Use |
|---|---|
| `/brand/logo-full.png` | Full horizontal logo (mark + name) on light backgrounds; site header |
| `/brand/logo-full-white.png` | Full logo on dark backgrounds |
| `/brand/mark.png` | Icon only (small headers, avatars) on light backgrounds |
| `/brand/mark-white.png` | Icon only on dark backgrounds |
| `/brand/favicon.ico` | Browser tab (`/favicon.ico`) |
| `/brand/favicon-32.png` | PNG favicon `<link rel=icon>` |
| `/brand/apple-touch-icon.png` | iOS home screen (180×180) |
| `/brand/icon-192.png` | Web app manifest |
| `/brand/icon-512.png` | Web app manifest / splash |
| `/brand/og-image.png` | Open Graph / Twitter link preview (1200×630) |
| `/brand/banner.png` | Wide feature banner (decks, landing sections, email headers) |
| `/brand/facebook-cover.png` | Facebook page cover (1640×624) |
| `/brand/facebook-profile.png` | Facebook / social profile picture (720×720) |
| `/brand/README.md` | This file |
| `/brand/brand.json` | Machine-readable name, colors, fonts and file paths |
