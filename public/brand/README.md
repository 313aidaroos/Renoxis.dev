# Renoxis brand kit

Real Renoxis logo (blue R + house + red stripe, RENOXIS wordmark). PNG only — never SVG, never redrawn.
Source: `renoxis-logo/final/` (2026-10-17 refresh).

| File | Size | Use |
|---|---|---|
| logo-full.png | 2400px wide, transparent | Full logo (mark + wordmark) on light backgrounds |
| logo-full-white.png | transparent | Full logo on dark/blue backgrounds |
| mark.png | 1024×1024, transparent | Header/app mark on light backgrounds |
| mark-white.png | 1024×1024, transparent | Header mark on dark backgrounds |
| favicon.ico | 16–64px | Browser tab (`/favicon.ico`) |
| favicon-32.png | 32×32 | PNG favicon |
| apple-touch-icon.png | 180×180 | iOS home screen |
| icon-192.png / icon-512.png | | Web app manifest |
| og-image.png | 1200×630 | Open Graph / social share |

## Colors
- Renoxis Blue `#1854D0` (primary, theme color)
- Roof Red `#D83030` (accent stripe)
- White `#FFFFFF`
- Background `#F5F7FB`

## Rules
- Keep clear space ≥ the width of the house window around the logo.
- Don't recolor, stretch, outline or add effects. Use the white versions on dark backgrounds.
